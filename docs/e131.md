# E1.31 (sACN)

What most Falcon and Kulp controllers and xLights set-ups speak. `e131.py` builds the packets and keeps
each controller's universes; `output.E131Device` sends them. Nothing here changes the other kinds.

## Saved devices

`"kind": "e131"`, `protocol: "e131"`, `ip`, `segments` (= LEDs, up to 1000), `universe` (1–63999,
default 1) and `channel` (1–510 in that universe, default 1). Universe and channel are only stored for
this kind. The light must end before universe 64000.

## On the wire

- UDP 5568, **unicast** to the controller's IP. Not multicast: many home networks don't pass it.
- E1.31-2018 data packet: root layer (`ASC-E1.17`, vector 4, a fixed CID), framing layer (vector 2,
  source name *HA-liday Show*, priority 100, no sync address, per-universe sequence, options, universe),
  DMP layer (vector 2, type 0xA1, start address 0, increment 1, count, start code 0, channels).
- 510 channels a universe (170 RGB pixels), xLights' default. A light's channels run on into the next
  universe: channel `(universe - 1) * 510 + channel - 1`, counted from 0.
- Up to 40 frames a second; a still frame is repeated every second, inside receivers' 2.5 s timeout.
- When the last light on a controller stops, every universe it used gets three packets with the
  Stream_Terminated option bit (0x40), so the controller lets go at once.

## Several lights on one controller

`e131.Universes` holds every universe sent to one IP. Each light writes its channels in and sends the
universes it touched whole, so two lights sharing a universe never blank each other. A light that stops
while others play on has its channels set to 0. Lights are claimed by `output.address(d)`:
`ip#u<universe>c<channel>` unless they start at universe 1 channel 1.

`js/controllers.js` (`nextUniverse`, `overlapping`) works in the same channel numbers.

## Checked

Only on the wire, with a fake receiver on 127.0.0.1:5568: lights of 200 and 100 LEDs on one IP, tested at
once, filled universe 1 (510 channels) and shared universe 2 (390 channels); stopping both sent three
terminated packets to each universe. No real controller yet.

## Open questions

- Universe size is fixed at 510. Some set-ups use 512; add a setting if anyone needs it.
- No E1.31 sync packets (universe synchronisation); lights sharing a controller update packet by packet.
