To play this show from an automation, use the Govee Light Show MQTT entities (pick the show, then press Play), or the hassio.addon_stdin action with input {"action": "play", "show": "…"}. The song plays on the speaker chosen above.

Devices need LAN Control switched on in the Govee Home app. Govee doesn't report segment counts, so press Test: a rainbow runs with a white dot stepping along it. Set Segments so the dot visits every segment once per lap, and tick Reverse if it runs the wrong way.

Lights not delivered yet? Pick the model and add a planned light, then build shows with it. ✓ realtime means Govee lists the model as supporting per-segment control; ⚠ unverified models may not. Segment counts aren't published, so 15 is a guess until you Test the real light. When it arrives, scan and choose Link to, or type its IP into the row. Its shows carry over.
